# 制作方案模板与 ChatGPT 提问脚手架（P2）

方案在用户的 Web ChatGPT project 里分段生成（一次要一大段会塌缩，见 chatgpt-assets.md §驱动规程），汇总保存为 `plan/production-plan.md`。

## 提示词语言与形态（提问时就要写死这条要求）

| 用途 | 语言/形态 | 原因 |
|---|---|---|
| **§16/§17 视频提示词** | **中文·分区关键词·`·`分隔** | 实测同一镜：英文散文 2000 字符只覆盖 5 个板块，中文关键词 750 字符覆盖 11 个；视频模型（国内模型）中文理解可靠。**不要英文散文，不要正/负两大段** |
| §3/§12/§13 图像素材提示词 | 英文正+负两栏 | 走 ChatGPT 自带图像模型，英文已实测有效 |
| §15 音乐提示词 | 英文，**≤450 字符** | Mureka 声明上限 1024 字符，1500 字符会判「提示词过长」失败 |

**提问时必须对 GPT 明确**：§17 每张卡直接产出**可复制粘贴的成品中文提示词**，不要再让我二次翻译或压缩——这次实测中，GPT 给的 5500–6200 字符英文提示词因为过长被整条丢弃重写，等于白做。

## 分段提问计划（5 轮，每轮≤4板块）

先发全局上下文（主题大纲、比例、总时长、目标观众），然后按轮次提问。每轮收到后即校验该轮清单，缺项立刻追问补齐，不带病进入下一轮。

| 轮 | 生成板块 |
|---|---|
| 1 | §1 项目定位 · §2 故事梗概 · §3 角色小传 · §4 人物间关系 |
| 2 | §5 完整剧本 · §6 叙事节奏规划 |
| 3 | §7 拍摄风格 · §8 摄影参数建议 · §9 色彩方案 · §10 镜头语言规则 |
| 4 | §11 详细分镜规划 · §12 场景设计 · §13 美术和道具清单 |
| 5 | §14 环境音设计 · §15 配乐方案 · §16 视频统一风格提示词 · §17 各分镜细节提示词 |

## 17 板块模板（= 完整性校验清单）

### §1 项目定位
类型/题材、目标观众、情绪基调、**视频画面比例**（必须与 manifest 一致）、目标总时长、传播平台。
**视觉基调（必填，全片唯一）**：①**电影参考**——指定 1 部主参考影片（至多再加 1 部辅助，不可逐分镜换参考：星火实测逐组混用不同 IP 会造成片段间质感漂移）；②**导演风格**——点名导演并列 3–5 条可执行特征（构图习惯/运镜偏好/光线处理/色彩倾向/节奏），不能只写名字。这两项是全片视觉的宪法：**§7 必须把它落地成规则，§12 每张场景提示词、§17 每镜【整体规格】风格行都必须逐字嵌入**，校验清单会查。

### §2 故事梗概
200–400 字，含起承转合与结尾钩子。

### §3 角色小传（每个角色一张卡）
| 字段 | 要求 |
|---|---|
| 小传 | 100 字内背景 |
| 性格 | 3–5 个关键词+一句行为例证 |
| 表演方式 | 语速/肢体习惯/标志性小动作（喂给视频提示词与配音风格） |
| 人物外形 | 年龄/身形/发型/面部特征，措辞可直接进图像提示词 |
| 服装设定 | 每套服装：名称+出现场景+材质颜色细节 |
| 核心道具 | 与该角色绑定的随身物 |
| 表情清单 | **6 个表情从该角色剧本里实际出现的情绪中选**（不要通用喜怒哀乐套餐），每个表情标表达强度与方式——由「表演方式」推导（克制型角色的怒是压着的：咬肌紧绷眼神下压；外放型才是瞪眼嘶吼） |
| 定妆图生成提示词 | **正提示词**（白底、三视图措辞、比例，**+性格外化**：站姿/体态/肩颈状态/默认神态按性格关键词写——内向者不挺胸叉腰）+ **负提示词**（不要文字/水印/多人/畸形手） |

### §4 人物间关系
关系图（文字描述即可）+ 每对关系的张力一句话。

### §5 完整剧本
按场次：场景标题（内/外·地点·日/夜）、**光线**、**氛围**、**人物动作**、**对话**（角色名: 台词，标注语气）。台词是后续配音与字幕的唯一来源，不得含糊。
**台词硬要求**：每句台词的措辞必须符合该角色 §3 的性格关键词与表演方式——语速快慢决定句长与断句、有口头禅就要出现、用词贴角色背景（受教育程度/职业/时代）；"标注语气"时直接引用 §3 表演方式的措辞（如"急促、句尾吞字"），不得所有角色一个腔调。**人物动作**同样从 §3 肢体习惯与标志性小动作推导。

### §6 叙事节奏规划
| 时间范围（精确到秒） | 一句话梗概（引 §5 场次号，不复述剧情） | 情绪走向 | 主要作用 |
|---|---|---|---|
| 0:00–0:08 | 场1：车站初见 | 期待浮现 | 开场钩子 |
各段之和 = 目标总时长。情绪走向列供 §15 配乐结构与 §17 情绪行引用。

### §7 拍摄风格
一句话风格定位 + 3–5 条可执行的视觉规则，**必须从 §1 的电影参考与导演风格推导**（写明"来自《影片》/某导演的哪个特征"），不另起炉灶。

### §8 摄影参数建议
虚拟机位：传感器/镜头组（如 35mm/50mm/85mm）、光圈景深倾向、快门感、帧率感——措辞将进入分镜提示词的 lens/镜头型号字段。
**场景×镜头搭配表（必产出）**：逐 §12 场景一行，从 §7 规则与 §1 导演风格推导——同一场景的镜头语言要成套，不能逐镜自由发挥：

| 场景 | 常用焦段 | 机位/角度倾向 | 景深与快门感 | 运镜偏好（§10 词表内） | 禁用手法 |
|---|---|---|---|---|---|
| 例：潜艇走廊 | 35mm 纵深 | 低机位·轻微仰角 | 深景深·90度快门感 | 缓推·跟移 | 手持晃动·俯拍 |

§17 每个镜头行的焦段/机位/运镜**必须从该场景对应行取值**（特写等特殊景别可用镜头组内其他焦段，但机位倾向与禁用手法仍受此表约束）。

### §9 色彩方案
主色板（3–5 色+色值）、高光/阴影倾向、LUT 风格描述、禁用色。

### §10 镜头语言规则
运镜词表（推/拉/摇/移/跟/升降/手持）、剪辑节奏规则、转场规则（硬切/叠化/匹配剪辑何时用）、越轴约束。

### §11 详细分镜规划（全片总表，三层结构）

**必须区分三层，不要混用「镜头」一词**：

```
分镜(叙事单元)  S02 站台记忆 7s
 └ 镜头(生成单元) S02-a 4s 独立生成 ／ S02-b 3s 并入S02-a同次生成
    └ 运镜段(镜头内的运动分段) 0-1s揭示 → 1-3.2s横移 → 3.2-4s减速
```

总表逐「镜头」一行——**纯结构表，只管骨架不管细节**：

| 分镜 | 镜头 | 时长(s) | 生成方式 | 场景 | 情绪(§6) | 一句话梗概 |
|---|---|---|---|---|---|---|

**镜头语言、动作、音效不在本表写**——它们只在 §17 出现一次（镜头语言的场景级一致性由 §8 搭配表保证）。本表是 §17 的骨架：§17 卡与本表生成单元一一对应，编号/时长/场景必须一致。

**硬约束**：
- 单次生成时长必须是 **4–15 的整数秒**（视频模型下限），不接受小数
- **一镜一场景（用户硬规则 2026-07）**：需要场景转换的内容必须拆成独立镜头单独生成，一个生成单元内尽量只有一个场景。跨场景蒙太奇确需并入时，每个场景切片都要绑定各自场景参考图并在【镜头】行逐一写明场景——但默认动作是**拆开**
- **镜头 ≥4s → 独立生成**（可单独重做，最可控，默认选这个）
- **镜头 <4s → 标记「并入上一镜」**，写进同一条提示词内切镜；否则 2s 的镜头也按 4s 计费再裁掉，浪费且跨生成一致性更差
- **切镜密度上限**：8 秒 ≤3–4 切；更多切镜就延长该生成单元时长（如 12s/5 切）——星火实测切镜过密会吞掉最后 1–2 拍，宁可生成长了后期修剪
- 各镜头时长之和 = 分镜时长；各分镜之和 = 目标总时长（因整数秒限制，规划时就按整数排，别留 7.5s 这种）
- 长镜头/一镜到底超 15s 必须拆段并标注「首尾帧衔接」，衔接点画面静态描述写明（供尾帧校验）

### §12 场景设计（每场景一张卡）
空间特征（布局/尺度/方位）、氛围（光线/天气/时段）、与剧本相关的**关键细节**（道具位置、文字牌匾等必须准确的元素）、**场景提示词**（正+负）。
**场景提示词的正提示词必须以 §1 的电影参考+导演风格特征开头**（如 "in the visual style of «流浪地球», heavy industrial sci-fi realism, GuoFan-style volumetric light…"），**并包含 §9 的主色板倾向**（主色/高光阴影倾向/禁用色）——场景图是后续所有分镜的底色与配色锚点，风格或配色跑偏都会传染全片。

### §13 美术和道具清单
| 道具类别 | 道具名称 | 道具描述 | 重要性（主要/次要） |
主要道具将生成白底三视图；次要道具只进场景提示词。
**裁剪闸（星火教训）**：P3 必须逐一对照本清单生成**全部**主要道具三视图；要省掉任何一个，先向用户说明并获批准、记入 state.md——不得静默裁剪（星火 8 个道具悄悄只做了 3 个，用户事后才发现）。

### §14 环境音设计
声音主题、声音风格、声音叙事（哪些段落靠声音讲故事）。

**关键**：环境音**不做独立音频生成**，而是随 §17 由视频模型开 `enableSound` 连画面一起生成——音画天然同步，也省一轮生成。所以本节只需给出（**词库制，不出逐镜清单**——逐镜落词由 §17 直接从词库取，避免"先列一遍再抄一遍"）：
- 全片声音基调（一段）
- **按场景**的音效词库（每场景 5–10 个中文关键词，如站台场景「站台底噪·行李箱滚轮·车门提示音·远处广播·列车怠速」）；§17 写各镜音效时从该镜所属场景的词库选 3–6 个
- 独白/外语台词的声音特征要求（语种·音色·情绪），供 §17【对白使用原则】引用

### §15 配乐方案
音乐风格（从 §1 视觉基调与情绪基调推导，写明参考影片配乐气质）、配乐结构、配乐场景清单、每段**音乐生成提示词**（正+负；供 Mureka V8；**≤450 字符**；含风格/乐器/情绪/节奏词）。
**配乐结构逐段必含**（段划分与 §6 叙事节奏表对齐，一段=一首独立生成）：

| 段 | 时间范围（对齐§6） | 音乐意图 | 能量曲线（何时进乐·渐强点·最强点·如何收） | 进出方式（淡入/硬进/跨段衔接） |
|---|---|---|---|---|

**配乐场景清单必须标注「无乐段」**——留白给环境音、对白或静默张力的区间；无乐也是配乐决策，后期不得擅自填满。这张表是 P4 生成（一段一首）与 P7 选段（逐段按意图选窗）的唯一依据。

### §16 视频统一风格提示词（中文关键词，全片复用块）

产出 3 个**中文关键词行**，每行 `·` 或 `、` 分隔，将被逐镜复制进 §17 四框架的对应行：

```
风格行：<§1电影参考+导演风格的落地关键词，**即 §7 那 3–5 条可执行规则的关键词化**（§7 每条规则都要在此行有对应词，不许另写一套）> + <实拍质感压AI感词组：电影实拍质感、真实物理光影、自然皮肤毛孔与织物纹理、35mm胶片颗粒、实拍摄影机运动、非CG感、非塑料感、非AI感>
色彩行：<主色+色值·点缀色·高光阴影倾向·禁用色，来自§9>
约束基块：<无字幕、无文字、无水印、无标志、无BGM配乐、无卡通、无动漫、无变形手、无多余肢体、无重复人物、无新增人物、无脸部漂移、无服装变化…>
```

**必须中文关键词式，不要写成英文长句散文。** 实测同一镜：英文散文 2000 字符只覆盖 5 个板块，中文关键词 750 字符覆盖 11 个板块，信息密度约 6 倍；且视频模型对中文理解可靠。**风格行全片唯一**——所有分镜共用同一行，不逐镜换参考。

### §17 各分镜细节提示词（每**生成单元**一张卡，最重要）

**输出格式固定为「四框架」**（2026-07 星火项目定稿，取代旧十区罗列——十区的信息全部收编进四框架对应行）。GPT 直接产出可复制粘贴的成品中文提示词（不要英文散文、不要正/负两大段）：

```
【整体规格】
场景:<本镜唯一场景·关键细节(招牌/涂装/光线/地面状态)·({{Node "场景图"}}绑定)>
风格:<§16 风格行原样复制（含§1电影参考+导演风格落地词+实拍质感压AI感词组）>
色彩:<§16 色彩行，可加本镜特有色>
情绪:<§6 该段情绪走向>
主体:<角色名({{Node "角色图"}}:年龄外形·全套服装单品与颜色——**按 §3 服装-场景对应表选本场景该穿的那套**，并挂对应着装三视图)、核心道具({{Node "道具图"}}:材质颜色)——每个主体都显式绑定参考图>
群演:<背景人流车流·略失焦·不看镜头·不遮挡主体·不穿主角同色服装·与任何主角长相无关>

【对白使用原则】   ←仅当本单元有台词才写此框架，无台词整块省略
<说话人·台词原文(与§5逐字一致)·语气与声音特征(从§3表演方式引用:语速/音色/说话习惯，如"急促压低、句尾吞字")·口型精确同步·除此句外无任何其他对白>

【镜头】   ←按时间顺序逐镜头一行
镜头N(a-b s):<运镜|焦段/机位/快门感——从 §8 该场景的搭配行取值，运镜动词在 §10 词表内>|<镜头内容(音效词并入:从 §14 该场景词库选 3–6 个)>
转场:<可选末行——按 §10 转场规则为下一单元做的构图/色彩准备，如"结尾让黄色车身色块靠近画面右缘"；写了它，剪辑阶段就必须真正执行对应转场(硬规则 10b)>
```

**【镜头】行内容的细节标准（用户要求 2026-07，细节密度直接决定成品准确度）**：
- **动作链**：人物动作用具体动词串联（"单膝落地不稳→站定→转向走廊深处"），不写"走过去""做动作"这类空词
- **物品移动**：写明起点→终点→运动方式（"将记录器插入控制柱侧端口·六道机械环依次亮起"），有状态变化的物件写清变化前后
- **特写镜头必写表情细节**：眉/眼/嘴/微表情的变化过程（"缓缓睁开全黑双眼·眼神从空无转为清醒的自由·嘴角微松"），只写"表情痛苦"不合格
- **动作与表情从 §3 推导**：动作链要体现该角色的肢体习惯与标志性小动作，表情表达强度按其表演方式定——**同一情绪，不同角色的演法必须不同**（克制型咬肌紧绷眼神下压，外放型才瞪眼嘶吼），不得全员一个演法
- **镜头语言从 §7/§8/§10 推导**：焦段/机位/景深/快门感从 §8 该场景的搭配行取，运镜动词在 §10 词表内、剪辑与转场遵守 §10 规则，整体手法不违反 §7 的可执行规则（如 §7 说"运镜克制单一"，镜头行就不能出现甩镜+急推组合）
- **在场者逐一点名 + 排除法**：画面里有谁、载具/容器里坐着谁、谁明确不在场（"舱内只有A与B，没有C"进【约束】）
- **一镜一场景**：单行镜头只落在一个场景；确需跨场景插切的，每个切片各自点名场景与参考图

```
【约束】
<§16 约束基块 + 本镜特殊注意（硬人设强调如"双眼必须全黑无眼白"、排除项如"舱内没有Eve"、防外溢如"路人与任何主角长相无关"）>
```

**排序规则**：框架顺序即优先级——整体规格先立世界观，镜头行逐拍展开，约束殿后。行内同理：主体一致性、动作、禁止项靠前。

| 校验 | 要求 |
|---|---|
| 时长 | 本单元时长 **4–15 整数秒**；【镜头】各行时间码首尾相接且总和 = 本单元时长 |
| 切镜密度 | 8s ≤3–4 个镜头行；超了就延长单元时长（星火实测过密会吞末拍） |
