# 制作方案模板与 ChatGPT 提问脚手架（P2）

方案在用户的 Web ChatGPT project 里分段生成（一次要一大段会塌缩，见 chatgpt-assets.md §驱动规程），汇总保存为 `plan/production-plan.md`。

## 提示词语言与形态（提问时就要写死这条要求）

| 用途 | 语言/形态 | 原因 |
|---|---|---|
| **§16/§17 视频提示词** | **中文·分区关键词·`·`分隔** | 实测同一镜：英文散文 2000 字符只覆盖 5 个板块，中文关键词 750 字符覆盖 11 个；视频模型（国内模型）中文理解可靠。**不要英文散文，不要正/负两大段** |
| §3/§12/§13 图像素材提示词 | 英文正+负两栏 | 走 ChatGPT 自带图像模型，英文已实测有效 |
| §15 音乐提示词 | 英文，**≤450 字符** | Mureka 声明上限 1024 字符，1500 字符会判「提示词过长」失败 |

**提问时必须对 GPT 明确**：§17 每张卡直接产出**可复制粘贴的成品中文提示词**，不要再让我二次翻译或压缩——这次实测中，GPT 给的 5500–6200 字符英文提示词因为过长被整条丢弃重写，等于白做。

## 分段提问计划（5 轮，每轮≤4板块）

先发全局上下文（主题大纲、比例、总时长、目标观众），然后按轮次提问。每轮收到后即校验该轮清单，缺项立刻追问补齐，不带病进入下一轮。

| 轮 | 生成板块 |
|---|---|
| 1 | §1 项目定位 · §2 故事梗概 · §3 角色小传 · §4 人物间关系 |
| 2 | §5 完整剧本 · §6 叙事节奏规划 |
| 3 | §7 拍摄风格 · §8 摄影参数建议 · §9 色彩方案 · §10 镜头语言规则 |
| 4 | §11 详细分镜规划 · §12 场景设计 · §13 美术和道具清单 |
| 5 | §14 环境音设计 · §15 配乐方案 · §16 视频统一风格提示词 · §17 各分镜细节提示词 |

## 17 板块模板（= 完整性校验清单）

### §1 项目定位
类型/题材、目标观众、情绪基调、**视频画面比例**（必须与 manifest 一致）、目标总时长、传播平台。

### §2 故事梗概
200–400 字，含起承转合与结尾钩子。

### §3 角色小传（每个角色一张卡）
| 字段 | 要求 |
|---|---|
| 小传 | 100 字内背景 |
| 性格 | 3–5 个关键词+一句行为例证 |
| 表演方式 | 语速/肢体习惯/标志性小动作（喂给视频提示词与配音风格） |
| 人物外形 | 年龄/身形/发型/面部特征，措辞可直接进图像提示词 |
| 服装设定 | 每套服装：名称+出现场景+材质颜色细节 |
| 核心道具 | 与该角色绑定的随身物 |
| 定妆图生成提示词 | **正提示词**（白底、三视图措辞、比例）+ **负提示词**（不要文字/水印/多人/畸形手） |

### §4 人物间关系
关系图（文字描述即可）+ 每对关系的张力一句话。

### §5 完整剧本
按场次：场景标题（内/外·地点·日/夜）、**光线**、**氛围**、**人物动作**、**对话**（角色名: 台词，标注语气）。台词是后续配音与字幕的唯一来源，不得含糊。

### §6 叙事节奏规划
| 时间范围（精确到秒） | 内容 | 主要作用 |
|---|---|---|
| 0:00–0:08 | … | 开场钩子 |
各段之和 = 目标总时长。

### §7 拍摄风格
一句话风格定位 + 3–5 条可执行的视觉规则（参照系导演/影片可选）。

### §8 摄影参数建议
虚拟机位：传感器/镜头组（如 35mm/50mm/85mm）、光圈景深倾向、快门感、帧率感——措辞将进入分镜提示词的 lens/镜头型号字段。

### §9 色彩方案
主色板（3–5 色+色值）、高光/阴影倾向、LUT 风格描述、禁用色。

### §10 镜头语言规则
运镜词表（推/拉/摇/移/跟/升降/手持）、剪辑节奏规则、转场规则（硬切/叠化/匹配剪辑何时用）、越轴约束。

### §11 详细分镜规划（全片总表，三层结构）

**必须区分三层，不要混用「镜头」一词**：

```
分镜(叙事单元)  S02 站台记忆 7s
 └ 镜头(生成单元) S02-a 4s 独立生成 ／ S02-b 3s 并入S02-a同次生成
    └ 运镜段(镜头内的运动分段) 0-1s揭示 → 1-3.2s横移 → 3.2-4s减速
```

总表逐「镜头」一行：

| 分镜 | 镜头 | 时长(s) | 生成方式 | 镜别与运动 | 画面内容(含人物动作) | 声音(含独白标注) | 主要场景 |
|---|---|---|---|---|---|---|---|

**硬约束**：
- 单次生成时长必须是 **4–15 的整数秒**（视频模型下限），不接受小数
- **镜头 ≥4s → 独立生成**（可单独重做，最可控，默认选这个）
- **镜头 <4s → 标记「并入上一镜」**，写进同一条提示词内切镜；否则 2s 的镜头也按 4s 计费再裁掉，浪费且跨生成一致性更差
- 各镜头时长之和 = 分镜时长；各分镜之和 = 目标总时长（因整数秒限制，规划时就按整数排，别留 7.5s 这种）
- 长镜头/一镜到底超 15s 必须拆段并标注「首尾帧衔接」，衔接点画面静态描述写明（供尾帧校验）

### §12 场景设计（每场景一张卡）
空间特征（布局/尺度/方位）、氛围（光线/天气/时段）、与剧本相关的**关键细节**（道具位置、文字牌匾等必须准确的元素）、**场景提示词**（正+负）。

### §13 美术和道具清单
| 道具类别 | 道具名称 | 道具描述 | 重要性（主要/次要） |
主要道具将生成白底三视图；次要道具只进场景提示词。

### §14 环境音设计
声音主题、声音风格、声音叙事（哪些段落靠声音讲故事）。

**关键**：环境音**不做独立音频生成**，而是**逐镜写进 §17 的「音效」行**，由视频模型开 `enableSound` 连画面一起生成——音画天然同步，也省一轮生成。所以本节只需给出：
- 全片声音基调（一段）
- **按镜头**的音效关键词清单（每镜 3–6 个中文关键词，如「站台底噪·行李箱滚轮·车门提示音·远处广播·列车怠速」），这些关键词会被直接抄进 §17 对应镜的音效行
- 独白所在镜的音效行还要写明：秒段 + 声音特征 + 日文原文（见 §17 模板）

### §15 配乐方案
音乐风格、配乐结构（对应叙事节奏表的时间段）、配乐场景清单、每段**音乐生成提示词**（正+负；供 Mureka V8）。

### §16 视频统一风格提示词（中文关键词，全片复用块）

产出 4 个**中文关键词块**，每块一行、`·` 分隔，将被逐镜复制进 §17：

```
【定位】<类型·地点·比例·纪实感·叙事基调>
【风格】<自然光/对比/胶片感/运镜克制度/构图留白，来自§7>
【色彩】<主色+色值·点缀色·高光阴影倾向·禁用色，来自§9>
【禁止】<字幕·水印·背景音乐·正脸特写·看镜头·动漫风·过曝HDR·镜头抖动·文字变形·手部畸形…>
```

**必须中文关键词式，不要写成英文长句散文。** 实测同一镜：英文散文 2000 字符只覆盖 5 个板块，中文关键词 750 字符覆盖 11 个板块，信息密度约 6 倍；且视频模型对中文理解可靠。

### §17 各分镜细节提示词（每**镜头**一张卡，最重要）

**输出格式固定为下面这套中文分区关键词，GPT 直接产出可复制粘贴的成品**（不要英文散文、不要正/负两大段）：

```
【定位§1】…
【本镜§11】S02-a 站台记忆·4秒·情绪§6：由观察转向期待
【风格§7】…
【色彩§9】…
【主体§3】<角色名·年龄外形·全套服装单品与颜色·景别·占画高比例·背影/侧影约束>
【场景§12】<地点·关键细节：招牌/信息屏/车辆涂装/光线/地面状态>
【镜头§8】<焦段·光圈·景深·机位高度·帧率·快门>
【运镜§10】<0-1s揭示 → 1-3.2s横移 → 3.2-4s减速>（运镜段，非切镜）
【切镜】<仅当本卡含多个<4s镜头并入生成时写：镜头1 0-3s … ／硬切 ／ 镜头2 3-7s …>
【表演§5】<动作链，箭头串联>
【群演】<背景人流车流·略失焦·不看镜头·不遮挡主体·不穿与主角同色服装>
【音效§14】<环境音关键词·独白秒段+声音特征+日文原文>
【转场§10】<为下一镜做的构图准备，如「结尾让黄色车身色块靠近画面右缘」>
【禁止§16】…
```

**排序规则**：越靠前的越被模型重视。**主体一致性、运镜、禁止项必须靠前**，色彩质感等装饰性描述靠后——长提示词存在注意力稀释，顺序即优先级。

| 校验 | 要求 |
|---|---|
| 时长 | 【本镜】时长为 **4–15 整数秒**；含【切镜】时，各小镜头时长之和 = 本镜时长 |
| 运镜段 | 【运镜§10】各段之和 = 本镜时长（运镜段是镜头内的运动分段，**不是切镜**） |
| 音效 | 每镜必须有【音效§14】行，否则该镜环境音无人负责 |
| 转场 | 写了【转场§10】的镜，剪辑阶段必须真正执行对应转场，不能只做硬切 |

**成品范例**（函馆片实测，753 字符覆盖 11 个板块，可直接喂视频模型）：

```
【定位§1】日式小清新剧情短片·函馆·16:9·实景纪实·克制叙事·记忆与释然
【本镜§11】S02站台记忆·7秒·情绪§6：由观察转向期待、熟悉感浮现
【主体§3】佐藤葵·26岁日本女性·浅灰褐及膝羊毛大衣·雾蓝针织衫·炭灰直筒裤·深棕短靴·燕麦围巾·米白帆布单肩包·深棕黑及锁骨直发微内扣·三分之二侧背影·占画高25%·不转向镜头·无正脸特写
【场景§12】函館駅站台·雨棚钢柱·黄色安全线·紫黄涂装特急北斗号·发车信息屏「今度の発車は」·圆形挂钟·远山·阴天散射光·地面微湿

【群演】车门处上下车乘客·拖行李箱旅客双向走动·柱边候车者·远处站务员·均略失焦不看镜头不遮挡主体不穿浅灰褐大衣

【风格§7】自然光优先不改阴天·低对比·富士负片感·柔和高光滚降·细腻胶片颗粒·单一明确运镜·留呼吸空间
【色彩§9】主色雾灰蓝#AAB7BD·点缀紫#6C5A86与银杏黄#D6A93C·冷调阴影暖调高光·禁青橙调·禁过饱和HDR
【转场§10】结尾让黄色车身色块靠近画面右缘，便于与下一镜色彩匹配
```

## 汇总后校验清单（全部勾完才进 Gate 1）

- [ ] 17 板块齐全，无占位符/「略」（**单主角片 §4 写「单主角，不适用」也算齐，不能整块缺失**）
- [ ] 比例、总时长与 manifest 一致；§6 与 §11 时长互相吻合
- [ ] 每个角色有定妆图提示词（正+负）；每个场景有场景提示词（正+负）
- [ ] **§11 用三层结构**：每个镜头标了时长(4–15整数秒)与生成方式(独立/并入上一镜)
- [ ] **§17 是中文分区关键词成品**，不是英文散文；每镜含【音效§14】行
- [ ] §17 每镜时长验算通过；运镜词汇在 §10 词表内
- [ ] §9 的色值真的出现在 §16/§17 的【色彩】行里（不能只写在 §9 自己那节）
- [ ] §14 的音效关键词真的逐镜落到 §17 的【音效】行里
- [ ] 台词完整可直接配音；**§15 提示词 ≤450 字符**可直接喂 Mureka
